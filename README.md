# বারাকাহ টাইম (Barakah Time)

স্ক্রিন টাইম কমানো, কাজে মন রাখা আর আল্লাহর স্মরণ — একসাথে। একটি Android অ্যাপ।

## কী করে

- **ঘণ্টাভিত্তিক লিমিট** — প্রতি ঘণ্টায় Facebook ১০ মিনিট, YouTube ১৫ মিনিট (বদলানো যায়)। কোটা শেষ হলে পরের ঘণ্টা পর্যন্ত বন্ধ।
- **শর্টস/রিলস ব্লক** — YouTube Shorts, Facebook Reels, Instagram Reels, TikTok। বাকি YouTube খোলা থাকে।
- **ইবাদত-গেট** — লিমিটেড অ্যাপ খোলার আগে নিয়তের প্রশ্ন, তারপর আয়াত পড়া / হাদিস পড়া / জিকির। প্রতিবার খুললে দাম একটু বাড়ে। সবসময় "থাক, ফিরে যাই" বাটন।
- **ভয়েস টাস্ক** — "সকাল ৯টা থেকে ১১টা অ্যাসাইনমেন্ট, তারপর বিকেল ৪টা থেকে ৫টা জিম" বললে দুটো টাস্ক হয়, সময়সহ।
- **ফোকাস ব্লক** — টাস্কের সময় সব লিমিটেড অ্যাপ বন্ধ।
- **রিমাইন্ডার** — টাস্কের শুরু/শেষে নোটিফিকেশন; টানা স্ক্রল করলে পরের কাজের কথা মনে করায়।
- **কঠোর মোড** — লিমিট ঢিলা করতে ৬০ সেকেন্ড অপেক্ষা।
- **জরুরি পাস** — দিনে ৩ বার, ৩৩ ইস্তিগফার + ৬০ সেকেন্ড অপেক্ষার পর ৩ মিনিট।

সব ডেটা ফোনেই থাকে। ইন্টারনেট পারমিশন নেই।

## APK বানানো (ফোন থেকেই)

1. GitHub-এ একটা নতুন রিপোজিটরি খুলুন, এই ফোল্ডারের সব ফাইল আপলোড করুন (`.github` ফোল্ডারসহ)।
2. রিপোর **Actions** ট্যাবে "Build APK" নিজে থেকে চলবে (৫–৮ মিনিট)।
3. শেষ হলে রিপোর **Releases**-এ `BarakahTime.apk` পাবেন — ফোনে ডাউনলোড করে ইনস্টল করুন।

কম্পিউটার থাকলে: Android Studio দিয়ে ফোল্ডারটা খুলে Run চাপলেই হবে।

## প্রথমবার চালু করা

1. অ্যাপ খুলে "Accessibility সেটিংস খুলুন" → "বারাকাহ টাইম" চালু করুন।
2. Android 13+ এ "Restricted setting" দেখালে: Settings → Apps → বারাকাহ টাইম → উপরের ⋮ → **Allow restricted settings**, তারপর আবার চালু করুন।
3. নোটিফিকেশন পারমিশন দিন।
4. Xiaomi/Oppo/Vivo/Samsung ফোনে ব্যাটারি সেটিংসে অ্যাপটিকে "No restrictions" দিন, নইলে ফোন সার্ভিস বন্ধ করে দিতে পারে।

## কোড কোথায় কী

| ফাইল | কাজ |
| --- | --- |
| `GuardService.java` | Accessibility পাহারাদার: সামনের অ্যাপ দেখা, সময় গোনা, গেট খোলা, শর্টস থেকে Back |
| `ShortsDetector.java` | শর্টস/রিলস স্ক্রিন চেনার view-id তালিকা (অ্যাপ আপডেটে বদলাতে হতে পারে) |
| `GateActivity.java` | থামার স্ক্রিন: নিয়ত, আয়াত/হাদিস/জিকির, ব্লক, জরুরি পাস |
| `Guard.java` | কখন ব্লক, কত মিনিট বাকি, সেশন |
| `TaskParser.java` | বাংলা/ইংরেজি বাক্য থেকে টাস্ক ও সময় |
| `Content.java` | আয়াত, হাদিস, জিকির — শেয়ার করার আগে একজন আলেমকে দিয়ে যাচাই করিয়ে নিন |
| `Reminders.java` | নোটিফিকেশন ও অ্যালার্ম |

`app/debug.keystore` শুধু ব্যক্তিগত ব্যবহারের সাইনিং কী — যাতে নতুন বিল্ড পুরোনোটার উপর আপডেট হিসেবে বসে। Play Store-এ দিতে চাইলে নতুন কী বানাবেন।
